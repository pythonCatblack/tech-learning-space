## 第十章 程序化建模与节点式生成

| 题号 | 答案 | 解析                                                                                      |
| ---- | ---- | ----------------------------------------------------------------------------------------- |
| 1    | A    | L-系统是0型语法（无限制语法），植物形态通常只用上下文无关子集，这是L系统理论的基础        |
| 2    | B    | H值越小（接近0），地形越崎岖；H值越大（接近1），地形越平滑，符合1/f^α噪声理论             |
| 3    | A    | 菱形端口的"空"输入不等于无数据，而是使用该节点内部的默认值/常量，而非依赖于上下文         |
| 4    | C    | F₂-F₁在Voronoi边界处梯度最大，可用作mask生成裂缝效果，这是程序化纹理中的常用技术          |
| 5    | B    | 雅可比矩阵的SVD分解可以分析约束系统的条件数，判断病态程度，这对约束求解器的稳定性至关重要 |

## 第十一章 逆向工程与点云处理

| 题号 | 答案 | 解析                                                                                |
| ---- | ---- | ----------------------------------------------------------------------------------- |
| 1    | A    | 深度分辨率Δd与d²成正比，距离增加导致分辨率恶化；这是远程激光雷达精度较低的原因      |
| 2    | A    | Max Pooling是置换不变函数，PointNet理论上可以逼近任意连续集合函数，这是其数学基础   |
| 3    | B    | SVD分解是最小二乘解，当异常点超过50%时，该解可能完全错误，需要鲁棒估计方法          |
| 4    | A    | 泊松方程源于物理守恒定律，深度增加使基函数更精细，但计算量指数增长（2^depth）       |
| 5    | D    | Chamfer Distance对局部噪声敏感，Hausdorff对整体偏差敏感，两者结合可全面评估点云质量 |
