11.1.2 激光三角测量原理

激光三角测量是工业3D扫描的核心原理，其数学基础是三角测量：

💡 激光三角测量数学
几何配置：
          激光发射器
              \
               \ α (入射角)
                \
    ────────────○──────────── 物体表面
                /
               / β (散射角)
              /
           相机

基本方程（余弦定理）：
d = B · sin(β) / sin(α + β)

其中：
- B：基线距离（激光-相机）
- α：入射角
- β：散射角
- d：被测点深度

分辨率推导：
Δd = d² · cos(β) / (B · sin(α))

关键洞察：
- 基线B越大，深度分辨率Δd越小（精度越高）
- 但B过大会导致遮挡问题
- 存在最优α+β=90°配置

💡 格雷码+相移法
格雷码编码（空间解包裹）：
- 二进制图案投射n次
- 每个像素获得唯一二进制码
- 范围：0到2ⁿ-1

相移法（相位展开）：
φ(x,y) = arctan2(Σ Iₖ·sin(2πk/n), Σ Iₖ·cos(2πk/n))

其中：
- Iₖ：第k帧投影强度
- n：相移步数（通常4-8）

绝对相位计算：
Ψ(x,y) = φ(x,y) + 2π·N(x,y)

其中N(x,y)是级次（由格雷码确定）

深度计算：
Z = f·B / (d + f·tan(α))

其中d是相机主点到匹配点的横向偏移

11.2.3 曲面法线估计

法线估计是点云处理的基础操作，用于曲面重建和可视化：

💡 PCA法线估计
算法步骤：
1. 对点p的k近邻构建局部邻域集合N(p)
2. 计算协方差矩阵C：
   C = (1/k) Σ_{q∈N(p)} (q - p)(q - p)ᵀ

3. 对C进行特征值分解：
   C·vᵢ = λᵢ·vᵢ,  λ₁ ≥ λ₂ ≥ λ₃ ≥ 0

4. 法线方向 = 最小特征值对应的特征向量
   n = v₃

朝向约束：
- 如果已存在参考点（如相机），确保n·(p - camera) > 0
- 或使用视图中多数法线朝向一致的约束

数学意义：
- λ₁, λ₂, λ₃表示点云在三个主方向的方差
- 最小特征值方向是局部曲面法线方向
- λ₃/(λ₁+λ₂+λ₃) 可作为平面度指标

11.3.3 点云配准

点云配准是将多个视角的点云对齐到统一坐标系的过程：

💡 ICP（Iterative Closest Point）算法
目标：找到变换(R, t)使得：
argmin_{R,t} Σ ||R·pᵢ + t - qᵢ||²

其中qᵢ是pᵢ的最近对应点

算法流程：
1. 对每个点pᵢ，在目标点云中找最近邻qᵢ
2. 用SVD计算最优变换(R, t)：
   - 计算中心：μₚ = mean(P), μ_q = mean(Q)
   - 去中心：P' = P - μₚ, Q' = Q - μ_q
   - 协方差：H = P' · Q'^T
   - SVD：H = U·Σ·Vᵀ
   - 最优旋转：R = V·Uᵀ
   - 若det(R) < 0，则R = V·diag(1,1,det(V·Uᵀ))·Uᵀ
   - 平移：t = μ_q - R·μₚ
3. 应用变换，迭代直到收敛

收敛判定：
- 均方误差变化 < 阈值
- 迭代次数达到上限
- 对应点距离均值 < 阈值

11.5.2 Poisson Surface Reconstruction

💡 泊松曲面重建数学
输入：点云P，带法线nᵢ
目标：找到指示函数χ使得∇χ ≈ nᵢ

泊松方程：
∇²f = ∇·n

其中：
- f：平滑的标量场
- n：法线场（视为梯度约束）

数值求解：
1. 构建八叉树空间划分
2. 在节点上定义基函数Φ
3. 最小二乘求解：min Σ||∇(Σ cⱼΦⱼ) - nⱼ||²
4. 提取等值面（Marching Cubes）

参数选择：
- Depth：八叉树深度（影响精度）
- Solver_Tolerance：求解器精度
- Weight：法线权重（平滑度）

第十一章选择题

1. 激光三角测量系统中，深度分辨率Δd=d²·cos(β)/(B·sin(α))。当被测物体距离d增加时，以下分析正确的是？
A. 深度分辨率单调恶化（Δd增加），这解释了为何远程激光雷达精度较低　B. 深度分辨率与d成正比，因此距离增加2倍意味着分辨率降低2倍　C. 当α+β=90°时，sin(α)和cos(β)均取最大值，此时分辨率最优　D. 增加基线B可以提高分辨率，但过大的B会导致近处物体出现遮挡

2. PointNet中Max Pooling实现置换不变性的数学本质是？该设计使得PointNet能够理论上保证什么？
A. Max Pooling是 symmetrized 函数，其输出与输入顺序无关；理论上可保证逼近任何连续集合函数　B. Max Pooling选择最大值点，丢弃了其他点的信息；理论上可保证点云的拓扑识别　C. Max Pooling是排列不变函数，但其效果受限于MLP的容量；理论上可保证100%分割精度　D. Max Pooling对所有点平等对待，不区分几何和颜色属性；理论上可保证语义分割的类别平衡

3. ICP算法的收敛性分析中，SVD分解求解最优旋转R=V·Uᵀ的数学依据是？当存在异常对应点时，该方法的鲁棒性如何？
A. SVD分解保证R是行列式为1的正交矩阵，且最小化Frobenius范数意义下的误差；存在异常点时需要预处理剔除　B. SVD分解求得的是最小二乘意义下的最优解；但该解在存在>50%异常点时可能完全错误　C. SVD分解的几何意义是找到使两点集对齐的正交变换；该方法对异常点天然免疫，不需要额外处理　D. SVD分解的复杂度O(n³)，其中n是点数；这限制了ICP在大规模点云中的应用

4. 泊松曲面重建中，指示函数χ的梯度∇χ被约束逼近法线场n。该约束的数学来源是？当八叉树深度增加时，重建结果如何变化？
A. 泊松方程∇²f=∇·n来源于物理学中的守恒定律；深度增加使基函数更精细，细节更丰富但计算量指数增长　B. 指示函数的梯度应指向法线方向这一约束来自曲面的微分几何；深度增加会导致过拟合噪声　C. 泊松约束是最小化平滑项和拟合项的加权和；深度增加会提高收敛速度但不影响最终精度　D. 该约束是隐式曲面表示的自然推广；深度Depth的取值应等于点云密度的对数

5. 在点云质量评估中，Chamfer Distance和Hausdorff距离的本质区别是？给定两个点云A和B，以下分析正确的是？
A. Chamfer Distance是双向的最近邻距离之和/平均，具有对称性；Hausdorff是单向最大最小距离，不对称　B. Chamfer Distance是O(n²)复杂度，适合大规模点云；Hausdorff是O(n log n)，适合实时应用　C. 两种距离都是度量空间中的真实距离，满足三角不等式；因此可以相互替代使用　D. Chamfer Distance对局部噪声敏感，Hausdorff对整体偏差敏感；实际评估应结合两者

参考答案

答案：1.A　2.A　3.B　4.A　5.D

解析：

  1. 深度分辨率Δd与d²成正比，距离增加导致分辨率恶化；这是远程激光雷达精度较低的原因。
  2. Max Pooling是置换不变函数，PointNet理论上可以逼近任意连续集合函数，这是其数学基础。
  3. SVD分解是最小二乘解，当异常点超过50%时，该解可能完全错误，需要鲁棒估计方法。
  4. 泊松方程源于物理守恒定律，深度增加使基函数更精细，但计算量指数增长（2^depth）。
  5. Chamfer Distance对局部噪声敏感，Hausdorff对整体偏差敏感，两者结合可全面评估点云质量。
