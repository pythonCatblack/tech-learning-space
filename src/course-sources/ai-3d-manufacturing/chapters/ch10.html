10.1 程序化建模的数学基础

10.1.1 形式语言与L-系统

程序化建模的核心思想源于Chomsky形式语法，最经典的实例是Lindenmayer系统（L-系统），用于描述植物形态的递归生成：

💡 L-系统的数学定义
L-系统是一个三元组 G = (V, ω, P)：

V：字母表（符号集合）
ω：初始串（公理）
P：产生式规则集合

示例：植物分支结构
字母表：V = {F, +, -, [, ]}
初始串：ω = "F"
产生式：P = {
  F → F[+F]F[-F]F,
  + → "+",
  - → "-"
}

解释：
- F：向前画线
- +：左转60度
- -：右转60度
- [：保存状态
- ]：恢复状态

迭代3次后的字符串推导：
F → F[+F]F[-F]F → ...
该字符串被解释为 turtle graphics 绘图指令

10.1.2 噪声函数与程序化纹理

程序化内容生成（PCG）广泛使用噪声函数作为基础构建块：

🌊

Perlin噪声

梯度噪声，在n维空间定义连续随机函数

📊

Simplex噪声

Perlin的优化版，消除方向性偏差

⚡

Worley噪声

基于Voronoi图的细胞噪声

🌀

分形布朗运动(fBM)

多八度噪声叠加：fBM(p) = Σᵢ aⁱ·noise(2ⁱp)

💡 分形布朗运动与1/f谱特性
fBM的核心性质：功率谱遵循1/f^α规律

数学定义：
fBM(p; octaves, lacunarity, gain) = Σ_{i=0}^{octaves-1} gainⁱ · noise(lacunarityⁱ · p)

其中：
- octaves：叠加层数（典型值4-8）
- lacunarity：频率倍增（典型值2.0）
- gain：振幅衰减（典型值0.5）

Hurst参数H与分形维数D的关系：
D = n + 1 - H （n是拓扑维数）
H = 1 - α/2

在程序化地形中：
- H ≈ 0.5：山脉地形
- H ≈ 0.7：崎岖地形
- H ≈ 0.9：极端崎岖地形

10.2 Blender Geometry Nodes

10.2.1 节点系统架构

Geometry Nodes是Blender 2.92+引入的基于节点的几何处理框架，采用数据流编程范式：

💡 Geometry Nodes核心概念
几何数据（Geometry Data）：
├── 顶点（Vertices）：位置、法线、UV
├── 边（Edges）：连接关系
├── 面（Faces）：拓扑信息
└── 点（Points）：实例化粒子

节点类型层次：
├── Input Nodes：Object Info, Group Input, Collection Info
├── Output Nodes：Group Output
├── Geometry Nodes：
│   ├── Mesh Operations：Subdivision, Decimate, Triangulate
│   ├── Point Operations：Point Distribute, Point Instance
│   └── Curve Operations：Curve to Mesh, Resample Curve
├── Attribute Nodes：
│   ├── Attribute Sample Texture
│   ├── Attribute Vector Math
│   └── Named Attribute
└── Utility Nodes：
    ├── Join Geometry
    ├── Capture Attribute
    └── Random Value

数据流：
[Input] → [Node A] → [Node B] → [Node C] → [Output]
                ↓
          中间几何数据通过匿名属性传递

10.2.2 字段（Field）系统与上下文

Geometry Nodes最难理解的概念是"字段"——在几何元素上定义的函数。菱形节点插座表示字段输入：

◆

◆ 菱形（字段输入）

在几何元素的每个元素上求值

○

○ 圆形（单值）

整个节点执行一次

💡 字段上下文的隐式推断
示例：Set Material节点

Material输入（◆）是字段：
→ 在几何体的每个面/点/边上独立求值
→ 上下文字典推断自输入几何

如果输入是面上下文：
Material = Attribute（面属性）

如果输入是点上下文：
Material = Attribute（点属性）

如果输入是编辑后的几何：
Material在编辑后重新求值

关键理解：
- 菱形端口的"空"输入不等于无数据
- 上下文由上游连接的线决定
- 在哪里使用决定了如何解释

10.3 Houdini程序化建模

10.3.1 Houdini架构概览

Houdini采用节点网络+参数面板的双重界面，其核心是SOP（Surface Operators）层级：

层级 全称 应用场景
SOP Surface Operators 几何体创建与编辑
POP Particle Operators 粒子系统
DOP Dynamic Operators 刚体/柔体动力学
COP Composite Operators 图像合成
VOP Vector Operators 程序化材质/噪声

10.3.2 VEX：Houdini的表达式语言

VEX（Vector Expression）是Houdini的高性能向量表达式语言，用于编写自定义节点：

💻 VEX代码示例：程序化岩石生成
// wrangle节点中的VEX代码
// 上下文：detail（每个基元执行一次）

// 获取当前点的位置
vector pos = @P;

// 生成基于位置的噪声位移
float noise_scale = ch("noise_scale");
float displacement = ch("displacement");

// 使用curl noise保持流体特性
vector noise_pos = pos * noise_scale;
float n = noise(noise_pos);

// 沿法线方向位移
@P += @N * n * displacement;

// 添加第二层细节
float detail = noise(pos * noise_scale * 3.0);
@P += @N * detail * displacement * 0.3;

// 随机旋转
float angle = rand(@ptnum) * 3.14159 * 2;
vector axis = normalize(pos);
@P =qrotate(@P, axis, angle * 0.1);

// 导出属性供材质使用
f@displacement_value = n;

10.4 参数化设计方法论

10.4.1 参数化设计的形式化

参数化设计将设计意图编码为数学约束和参数关系：

💡 参数化设计的数学框架
设计空间（Design Space）：
D = {d₁, d₂, ..., dₙ}  // n个设计参数

约束空间（Constraint Space）：
C = {c₁, c₂, ..., cₘ}  // m个约束条件

设计问题：
Find d ∈ D
Such that: C(d) = 0 (等式约束)
         C(d) ≥ 0 (不等式约束)
         Optimize: F(d) (目标函数)

示例：参数化椅设计
D = {seat_height, seat_depth, back_angle, leg_width, ...}
C = {
  seat_height ∈ [40, 50]cm,
  seat_depth ∈ [40, 50]cm,
  back_angle ∈ [95, 110]°,
  structural_stress(seat_height, leg_width) ≤ σ_max
}
F = manufacturing_cost + weight

10.6 程序化材质与纹理

10.6.1 Shader Nodes数学

Blender的Shader Nodes本质上是在UV坐标上定义的数学函数。理解这些运算的数学本质对于高级材质创作至关重要：

💡 程序化材质节点图论
材质定义为一个有向无环图（DAG）：
M = (V, E, A)
其中：
- V：节点集合（操作）
- E：边集合（数据流）
- A：属性集合（常量参数）

每个节点v∈V是一个函数：
f_v : (Input₁, Input₂, ...) → Output

示例节点图：
[Noise Texture] → [Color Ramp] → [Principled BSDF]
      ↓
[Coordinate] ──────────→ [Mapping] → [Image Texture]

语义等价于：
color = color_ramp(noise_texture(coord))
material = principled_bsdf(color)

10.6.2 Voronoi与程序化纹理

Worley噪声（Voronoi）是程序化纹理的核心构建块：

💡 Voronoi图与Worley噪声
给定点集P={p₁,p₂,...,pₙ}，Voronoi单元：
V(pᵢ) = {x ∈ ℝⁿ | dist(x,pᵢ) ≤ dist(x,pⱼ), ∀j≠i}

Worley噪声Fₖ(x)：
Fₖ(x) = 第k近邻点pᵢ的距离 = dist(x, pᵢₖ)

变体：
- F₁：最近邻距离（细胞核心）
- F₂-F₁：到最近边距离（细胞边界）
- F₃：第三近邻距离

应用：
- 岩石/石材：F₂-F₁作为细节mask
- 泡沫：F₁作为单元格
- 织物：F₂-F₁配合低octaves

10.9 本章小结

📚 核心要点
  1. L-系统是形式语言理论在程序化建模中的应用，通过递归产生式规则生成复杂形态

第十章选择题

1. L-系统的数学框架(G={V,ω,P})中，迭代产生的字符串长度增长速率为指数级。关于L-系统与Chomsky语法层次的关系及其在植物形态模拟中的适用性，以下分析正确的是？
A. L-系统是0型语法（无限制语法），可生成任意复杂度的结构，但植物形态通常只用上下文无关子集　B. L-系统中"["和"]"操作符的引入使系统超越了点阵自动机的表达能力　C. 典型的植物分支结构可以用L-系统生成，但无法表达对称性（如花瓣）　D. L-系统的字符串长度增长不影响其作为物理植物生长模型的有效性，因为植物生长是并行的

2. 分形布朗运动fBM(p;octaves,lacunarity,gain)=Σgainⁱ·noise(lacunarityⁱ·p)的Hurst参数H与分形维数D的关系D=n+1-H(n为拓扑维数)。对于二维地形模拟，以下Hurst参数与地形特征的分析，正确的是？

3. BlenderGeometryNodes中，"字段"系统的核心特征是菱形端口表示在几何元素上求值的函数。关于字段上下文的隐式推断规则，以下分析错误的是？
A. 菱形端口的"空"输入不等于无数据，而是使用该端口的默认值　B. 字段输入的求值上下文由上游连接的输出端口决定　C. CaptureAttribute节点允许在几何通过时保存字段值供后续节点使用　D. 在MeshCircle节点中，位置属性存在于顶点上下文中，因此可以在顶点上对位置进行运算

4. 程序化材质中，Voronoi图（worley噪声）的F₂-F₁变体表示到最近Voronoi边界的距离。关于该变体的数学性质与纹理应用，以下分析正确的是？
A. F₂-F₁的值域为[0, r]，其中r是最近邻与次近邻点的最大可能距离　B. F₂-F₁在Voronoi单元内部是线性函数，在边界处梯度不连续　C. 当应用于程序化岩石纹理时，F₂-F₁可用作mask来生成裂缝效果，因为其梯度在边界最大　D. Voronoi噪声的方向各向同性使其无法表达木材年轮等具有方向性的纹理

5. 在参数化设计框架中，约束传播算法处理循环约束时需要迭代求解。关于循环约束的数值稳定性与求解方法，以下分析正确的是？
A. 循环约束总是存在唯一解，因为设计参数数量等于约束数量　B. 雅可比矩阵的奇异值分解（SVD）可以判断约束系统的病态程度　C. 梯度下降法在约束优化中总是比牛顿法收敛更快，因为不需要计算二阶导数　D. 惩罚函数法将约束转化为目标函数项，但会导致病态优化 landscape

参考答案

答案：1.A　2.B　3.A　4.C　5.B

解析：

  1. L-系统是0型语法（无限制语法），植物形态通常只用上下文无关子集，这是L系统理论的基础。
  2. H值越小（接近0），地形越崎岖；H值越大（接近1），地形越平滑，符合1/f^α噪声理论。
  3. 菱形端口的"空"输入不等于无数据，而是使用该节点内部的默认值/常量，而非依赖于上下文。
  4. F₂-F₁在Voronoi边界处梯度最大，可用作mask生成裂缝效果，这是程序化纹理中的常用技术。
  5. 雅可比矩阵的SVD分解可以分析约束系统的条件数，判断病态程度，这对约束求解器的稳定性至关重要。
