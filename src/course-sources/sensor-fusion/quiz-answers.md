## 第一章 传感器融合概论：让无人机"看见"真实世界

### 章节概述

- 主题：传感器融合概论
- 核心概念：三种融合范式（互补/竞争/协同）、融合层次（数据/特征/决策）、信息论框架

### 课后测验答案

| 题号 | 答案  | 解析                                                                                                                                                                                                             |
| ---- | ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | **C** | 传感器融合的理论上界由贝叶斯最优估计决定，实际差距源于计算复杂度约束（实时性限制了优化迭代次数）、传感器独立性假设被违背（多传感器观测之间存在相关性）以及噪声模型的不准确性（实际噪声往往是非高斯的重尾分布）。 |
| 2    | **C** | 互补融合中误差负相关时，融合后方差可显著低于任一单传感器——这源于误差协方差矩阵非对角元素为负时产生的相消效应，而非简单的线性叠加。                                                                               |
| 3    | **D** | 一致性检测的理论基础是贝叶斯模型选择：通过计算传感器故障假设与环境变化假设的似然比（likelihood ratio），与预设阈值比较来区分两种情况。                                                                           |
| 4    | **A** | 原始数据层融合信息损失最少，但高维数据导致维度灾难（Curse of Dimensionality），使得估计器性能反而下降，这是信息论与计算复杂度之间的根本权衡。                                                                    |
| 5    | **D** | 因子图紧耦合架构在所有传感器失效时具有最优的fail-safe特性：任何一个传感器的失效仅导致对应的因子节点被移除，其他传感器的约束仍然有效，系统可以降级运行而不完全崩溃。                                              |

## 第二章 无人机平台与传感器系统架构

### 章节概述

- 主题：无人机平台与传感器系统架构
- 核心概念：飞控分层架构、实时性约束、PTP时间同步

### 课后测验答案

| 题号 | 答案  | 解析                                                                                                                                   |
| ---- | ----- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | **A** | 相位裕度要求90度时，感知延迟τ与姿态环带宽ω_c应满足τ < π/(2ω_c)，这是从频率域稳定性分析推导出的严格数学约束。                           |
| 2    | **C** | 总线带宽与感知算法计算量的匹配本质上是实时调度问题：数据产生速率R_bps与总线带宽B以及处理延迟τ之间需满足R_bps × τ ≤ B × T的稳定性条件。 |
| 3    | **D** | 感知系统不能无限制分配功耗，因为电池容量有限，功耗增加直接缩短续航，感知精度与续航之间存在帕累托最优边界——这是嵌入式系统的根本约束。   |
| 4    | **A** | PTP通信链路非对称性是理论下限，因为发送和接收路径的物理延迟天然不同，即使时间戳精度无限高也无法消除这种结构性非对称。                  |
| 5    | **C** | Buffer深度需容纳最大采样周期差（50ms - 1ms = 49ms）期间累积的数据，且插值应使用双线性插值以获得时间对齐的精确估计，而非最近邻丢弃。    |

## 第三章 相机与计算机视觉基础

### 章节概述

- 主题：相机与计算机视觉基础
- 核心概念：针孔模型、内参标定、双目视差、事件相机

### 课后测验答案

| 题号 | 答案  | 解析                                                                                                                                                                     |
| ---- | ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1    | **D** | 三维到二维投影损失了深度维度和尺度信息，尺度可通过IMU加速度积分恢复（积分得到位移与视觉估计的位移对比），但绝对深度仍存在尺度模糊性——这是投影变换本身的信息论本质损失。  |
| 2    | **A** | 深度方差σ²_Z ≈ (Z⁴/b²f²) × σ²_d，当Z→∞时σ²_Z→∞——这意味着距离越远，深度的相对不确定性越大，最终完全失效。                                                                 |
| 3    | **C** | 事件相机的信息获取模式是亮度变化的微分（导数），不存在全局曝光导致的运动模糊，其信息速率远高于传统相机的固定帧率，这是时域采样方式的本质区别。                           |
| 4    | **D** | 5参数模型只能建模径向和切向畸变，当镜头视场角超过120度时，高阶径向项和交叉项变得显著，必须使用8参数Rational模型。                                                        |
| 5    | **A** | 尺度不可观测的本质是scaling invariance——对同一投影结果，缩放所有深度和位移可以得到完全相同的图像。相机向下观察平面时可从Homography约束部分恢复尺度，但纯旋转时仍不可观。 |

## 第四章 激光雷达原理与点云处理

### 章节概述

- 主题：激光雷达原理与点云处理
- 核心概念：ToF测距、FMCW、点云滤波、运动畸变校正

### 课后测验答案

| 题号 | 答案  | 解析                                                                                                                                             |
| ---- | ----- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1    | **C** | FMCW距离R = c·f_b/(2S)，测距精度σ_R = c/(2S)·σ_f；近距离时f_b较大，相对误差σ_R/R更小，因此FMCW在近距离精度优于ToF（ToF精度受限于时钟分辨率）。   |
| 2    | **D** | 运动畸变校正公式为P_corrected = P_raw(t) + v×(T-(t-t₀))，当T=100ms、v=10m/s时，100m处误差为1m，对应角度误差约0.01弧度。                          |
| 3    | **A** | 非均匀点云导致特征提取的统计特性变化，基于均匀分布假设的阈值参数失效；补偿策略包括非均匀加权采样、体素网格动态调整、基于点密度自适应的特征阈值。 |
| 4    | **C** | 手眼标定AX=XB解的唯一性与旋转轴的充分激励相关；单轴旋转导致平移向量t的标定方程出现奇异性，因为所有位姿变换的旋转轴相同，平移部分的求解严重病态。 |
| 5    | **D** | 误差 = v×T = 27.8×0.1 = 2.78m；100m处误差2.78m已接近车辆宽度，高速场景下必须增加安全裕度，决策时需考虑感知延迟导致的系统位置误差。               |

## 第五章 IMU与惯性导航

- 核心概念：MEMS原理、艾伦方差、四元数、IMU预积分

### 课后测验答案

| 题号 | 答案  | 解析                                                                                                                                                                  |
| ---- | ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | --- | --- | --- |
| 1    | **D** | 随机游走的PSD在低频与1/τ成正比（-0.5斜率），零偏不稳定性在中间频段呈1/f（0斜率平坦区）；艾伦方差通过不同簇时间τ的聚合效应将这两种不同频率特性的噪声在时域上分离。     |
| 2    | **A** | 1分钟时ARW主导（σ≈0.039°），10分钟时ARW仍主导（σ≈0.12°），1小时时零偏不稳定性占主导（σ≈10°）——不同时间尺度由不同噪声源主导。                                          |

| 4    | **D** | 预积分假设积分区间内四元数变化缓慢；大角度旋转时一阶泰勒展开截断误差增大，误差与旋转角度平方成正比；需使用RK4或重新线性化。                                           |
| 5    | **A** | 高速旋转可能导致陀螺仪角速度超出量程产生饱和，同时振动干扰（g-sensitivity）影响科里奥利力测量，离心加速度也会影响加速度计读数——这些都是MEMS物理结构导致的高动态效应。 |

## 第六章 GPS/GNSS与绝对定位

### 章节概述

- 主题：GPS/GNSS与绝对定位
- 核心概念：伪距方程、RTK差分、毫米波雷达

### 课后测验答案

| 题号 | 答案  | 解析                                                                                                                                                                                   |
| ---- | ----- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | **D** | Newton-Raphson迭代的收敛性要求初始估计在真值附近（足够大的吸引域）；城市峡谷中多径效应导致伪距观测值存在较大异常值，使Jacobian矩阵病态，即使GDOP较小，迭代也可能发散或收敛到局部最优。 |
| 2    | **A** | 双频RTK通过双频观测组合消除电离层延迟一阶项，但基线超过20km时，未模型化的电离层残差、对流层残差及多径效应超过模糊度固定阈值（通常<0.1周），导致搜索空间指数膨胀，成功率急剧下降。      |
| 3    | **C** | 位置误差 ≈ ½ × 0.01 × 5² = 0.125m；占飞行距离的0.25%，对避障影响有限，但低速或悬停时可能导致障碍物地图错位。                                                                           |
| 4    | **D** | FMCW雷达的速度模糊取决于chirp周期T_c：v_max = λ/(4T_c)，超过此值出现速度模糊；多普勒只能测径向速度，切向速度需通过连续帧位置差分估计。                                                 |
| 5    | **A** | 可观测性分析表明：4-5颗卫星且分布不佳时，位置和时钟偏差估计存在耦合；转弯或加速机动中IMU偏差与运动耦合导致系统性偏差；需加入外部约束（地图匹配、视觉里程计）增强可观测性。             |

## 第七章 时空标定实战

### 章节概述

- 主题：时空标定实战
- 核心概念：时钟同步、手眼标定AX=XB、Kalibr工具链

### 课后测验答案

| 题号 | 答案  | 解析                                                                                                                                                                                  |
| ---- | ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | **C** | 纯旋转运动时，A和B矩阵的旋转部分可以可靠估计，但平移部分的方程出现奇异性——因为平移向量在纯旋转下不提供额外的约束信息，Schur补降维后系数矩阵秩不足；多轴复合运动保证平移向量的可观性。 |
| 2    | **D** | CRLB ≈ T_IMU / (√12 × SNR × √N)，时间偏移估计精度随样本数增加而提升，但受限于IMU离散采样造成的量化噪声；实际中可达0.1-0.5个IMU采样周期。                                              |
| 3    | **A** | 亚像素角点检测精度通常为0.1-0.3像素，1像素相当于约5σ置信水平，因此<1像素代表标定结果在统计上显著优于随机误差。                                                                        |
| 4    | **C** | 弹性形变导致外参矩阵偏离标定值，融合系统产生系统性偏差，误差不随观测增加而消除（持续偏置）；缓解策略包括刚性支架、减振垫圈、定期原位标定验证、在线标定。                              |
| 5    | **D** | 影响程度取决于运动状态：高速旋转时Δt×ω产生的等效角度误差占主导；高速平移时Δt×v和ΔR×p产生的平移误差更显著；旋转误差在高动态时影响更大。                                                |

## 第八章 概率滤波理论基础

### 章节概述

- 主题：概率滤波理论基础
- 核心概念：贝叶斯滤波、协方差传播、Mahalanobis距离、熵

### 课后测验答案

| 题号 | 答案  | 解析                                                                                                                                                                                         |
| ---- | ----- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | **A** | 熵是不确定性的度量；先验熵小意味着先验分布尖锐（高置信度），似然熵大意味着观测噪声大（信息量低）；信息增益 = H_prior - H_posterior，当似然信息量不足时，后验几乎等于先验。                   |
| 2    | **C** | 当A奇异时，y的维度降低，协方差矩阵的秩也会降低（Σ_y = rank(A) ≤ min(rank(Σ_x), rank(A))）；实际场景：三维位置投影到二维图像平面，深度方向的不确定性完全丢失（不可逆降维）。                  |
| 3    | **D** | PHᵀ项代表预测状态与观测之间的交叉协方差，反映状态估计不确定性如何"投影"到观测空间；如果S被低估，Mahalanobis距离被系统性地低估，异常观测无法被正确检测，导致滤波器对异常值过度响应。          |
| 4    | **A** | 高斯假设下滤波器将重尾噪声错误建模，导致极端残差的Mahalanobis距离被低估，给予过大权重，造成估计偏移甚至发散；鲁棒估计器通过修改损失函数降低异常值权重。                                      |
| 5    | **C** | IMU采样频率增加减少每步积分时间，但同时增加计算量；在固定算力下，更高采样频率意味着每步可用计算时间减少，可能导致数值积分精度下降；最优采样频率由IMU噪声特性和算力共同决定，存在收益递减点。 |

## 第九章 卡尔曼滤波与EKF/UKF

### 章节概述

- 主题：卡尔曼滤波与EKF/UKF
- 核心概念：KF五公式、EKF线性化、UKF Sigma点、Q/R调参

### 课后测验答案

| 题号 | 答案  | 解析                                                                                                                                                                                                                                                            |
| ---- | ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | **D** | KF最优性要求：线性系统、高斯噪声、精确已知的Q和R、完美的系统模型；实际中常见违背包括：非线性系统、非高斯噪声（如多径导致的重尾分布）、Q/R标称值与实际不匹配、模型不完整；当条件违背时，KF估计变为次优，实际误差可能显著大于理论协方差P所预测的值。              |
| 2    | **C** | 线性化误差来源于截断泰勒展开的高阶项；当状态不确定性大（高速机动时预测分布展开宽）或系统强非线性时，高阶项不可忽略，导致后验均值和协方差严重失配；改进方法：迭代EKF（IEKF）、使用UKF的Sigma点方法、或切换到基于优化的方法。                                     |
| 3    | **A** | α控制Sigma点围绕均值的散布程度（通常0.001≤α≤1），κ为额外缩放参数（通常设为0或3-n）；当n增大时，Sigma点数量2n+1增加，但主要复杂度来自协方差矩阵的Cholesky分解（O(n³)）；UKF对强非线性精度更高，但EKF在一阶精度足够且n较大时计算量更小。                          |
| 4    | **D** | 可辨识性问题意味着Q、R、P₀的绝对值无法从观测数据中唯一确定——只有它们的相对比例才是可辨识的；实践中通常先从传感器数据手册（Allan Variance）确定Q和R的绝对值，再用飞行数据微调相对比例。                                                                          |
| 5    | **A** | 当匹配率下降时，残差的实际协方差会增大，但固定的R矩阵无法反映这个变化；如果R保持不变，Mahalanobis距离被低估，导致异常残差获得过大权重，估计偏移；自适应方法：在线估计R（如自适应卡尔曼滤波、Strong Tracking Filter），或使用鲁棒M估计器自动降低异常残差的权重。 |

## 第十章 因子图与非线性优化

### 章节概述

- 主题：因子图与非线性优化
- 核心概念：因子图表示、非线性最小二乘、LM算法、iSAM2增量平滑

### 课后测验答案

| 题号 | 答案  | 解析                                                                                                                                                                                                                           |
| ---- | ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1    | **A** | IMU预积分残差通常是6维（3维旋转误差+3维位置误差），视觉重投影残差是2维（图像平面坐标误差）；由于维度不同，两类残差的量纲不一致（角度/米 vs 像素），不能直接相加；必须通过协方差矩阵的逆（信息矩阵）进行加权。                  |
| 2    | **C** | 迭代初期目标函数值大，说明当前解远离最优解；此时高斯-牛顿近似在当前位置可靠性差，直接使用会导致更新步过大甚至发散；λ大时LM近似于梯度下降（保守但保证收敛），λ小则接近高斯-牛顿（激进但可能发散）。                             |
| 3    | **D** | iSAM2通过变量消除顺序构建贝叶斯树，每次新观测加入时，只有沿着贝叶斯树中受影响路径的节点需要重新消元；其他分支保持原有的因子分解不变；数学基础是Cholesky分解的稀疏性和变量消除的图论解释。                                      |
| 4    | **A** | 边缘化将待消除变量对保留变量的约束以先验因子的形式近似表达；如果Schur补计算存在近似（如忽略高阶项），被边缘化变量的信息不能完整传递，导致先验约束弱于真实约束；长期运行会造成累积误差（能量泄漏），滤波器协方差膨胀。          |
| 5    | **B** | 条件数是最大奇异值与最小奇异值的比值，反映Hessian矩阵的特征值分布；增加优化变量时，不同变量之间的尺度差异（如角度偏差1°vs位置偏差1m）导致Hessian矩阵病态；条件数越大，迭代收敛越慢；实践中需要对不同变量的残差进行尺度归一化。 |

## 第十一章 视觉惯性融合(VIO)

### 章节概述

- 主题：视觉惯性融合(VIO)
- 核心概念：MSCKF、VINS-Mono、IMU预积分、滑动窗口边缘化

### 课后测验答案

| 题号 | 答案  | 解析                                                                                                                                                                                                                                          |
| ---- | ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | **A** | 将特征点加入状态向量会显著增加状态维度（每个特征点3维），导致协方差矩阵维度爆炸（O(N²)）；此外，特征点的观测方程是非线性的（投影除法），线性化误差随特征点深度增大而加剧；MSCKF只保存位姿，特征点仅在三角化成功时用于构造更新，状态维度固定。 |
| 2    | **C** | 评分范围[0,1]，1.0表示完全相同；假阳性来源：场景外观高度重复（如相似的走廊、森林），不同位置可能有非常相似的视觉词汇；几何验证通过2D-2D对极几何（RANSAC+八点法）检验两帧之间的相对位姿是否满足旋转矩阵的约束，剔除不一致的候选。              |
| 3    | **D** | 中点积分误差为O(dt²)，RK4误差为O(dt⁴)；对于高频IMU采样（如dt=0.5ms），中点积分精度已足够——累积误差主要来自零偏漂移而非数值积分；RK4每步需要4次IMU函数求值，计算代价约为中点积分的4倍。                                                        |
| 4    | **A** | 静止初始化时，加速度计测量值 = 重力向量 + 零偏，零偏和重力方向耦合——无法区分"机体倾斜"和"零偏偏移"；速度为零时，尺度也不可观；当无人机有速度时，尺度可以通过运动中IMU加速度积分的位移与视觉估计的位移对比来确定。                             |
| 5    | **B** | 高速机动时：相机运动模糊导致特征点定位精度下降；IMU预积分中高速旋转使一阶泰勒展开截断误差增大；两者失效机制不同：视觉失效是观测质量问题，IMU失效是模型近似精度问题（线性化假设被破坏）。                                                      |

## 第十二章 激光雷达与视觉融合

### 章节概述

- 主题：激光雷达与视觉融合
- 核心概念：LIO-SAM、LOAM边缘线匹配、LVI-SAM、Scan Context

### 课后测验答案

| 题号 | 答案  | 解析                                                                                                                                                                                                                                   |
| ---- | ----- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | **A** | 精度瓶颈在于Lidar点的稀疏性与图像像素密度的不匹配——特征层融合时需要将Lidar特征与图像特征建立对应关系，当Lidar空间分辨率不足时，可靠的特征匹配数量受限；最终融合精度仍受限于两个传感器中最差的那个的信息量（就像木桶原理）。            |
| 2    | **C** | 边缘点残差梯度方向沿边缘法平面；当存在两条平行等距边缘时，沿两条边缘法线方向的梯度分量相同——运动估计沿平行方向的偏移无法被边缘点约束区分，导致信息矩阵奇异性，优化求解器可能在该方向产生较大误差。                                     |
| 3    | **D** | 同一地点顺时针扫描和不同时刻扫描的Scan Context描述子在行方向有循环位移，位移量等于扫描角度偏移；余弦相似度对这种行偏移敏感；循环对齐需要遍历所有可能的位移量（O(N×M)），复杂度O(N²)，实际中通过FFT加速到O(N log N)。                   |
| 4    | **A** | LVI-SAM通过因子图中的"互观测因子"（Cross-modality factors）约束——Lidar里程计的位姿估计和视觉里程计的位姿估计在相同时间节点上存在一致性约束；检测机制：计算两个子系统输出位姿的Mahalanobis距离，超过阈值时降低对应因子的权重。          |
| 5    | **C** | 时间偏移会导致因子图优化器在跨模态约束上产生系统性误差（因为互观测因子的时间戳对应关系错误会导致残差计算不准确）；系统通过在线标定估计时间偏移——将时间偏移量作为优化变量加入因子图，与里程计状态共同优化，目标函数包含时间偏移残差项。 |

## 第十三章 融合定位与建图

### 章节概述

- 主题：融合定位与建图
- 核心概念：SLAM系统、回环检测、重定位、地图管理

### 课后测验答案

| 题号 | 答案  | 解析                                                                                                                                                                                                                                                                   |
| ---- | ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | **A** | 单目VIO的基本不可观测方向为：重力旋转（绕重力轴的旋转）和尺度漂移；当无人机匀速运动时，没有足够的加速度激励来区分重力方向和IMU零偏偏移——重力可以被重新定义同时调整零偏来"解释"观测；不可观测方向的存在使得状态估计协方差在某些方向上会无限增长。                       |
| 2    | **C** | 感知混淆与场景特征分布的熵相关——高重复场景特征分布的熵低，大量不同位置产生相同的视觉单词；增大词典容量可以提高区分能力，但当场景本身缺乏独特性时，增加词汇也难以区分；解决方案：增加几何验证的严格程度，或引入地点的语义上下文特征。                                   |
| 3    | **D** | 回环因子连接相距很远的节点，产生远程依赖关系，使Hessian矩阵原本的稀疏结构变得稠密；这不仅改变了矩阵结构，也改变了其特征值分布——通常会使条件数增大，使原本沿短程约束方向的收敛性变差，需要更多迭代才能收敛。                                                            |
| 4    | **A** | 跟踪特征数量阈值基于信号检测理论——当特征数过少时，视觉约束信息不足导致估计不可靠；新息卡方检验基于统计假设检验——检验观测是否符合预测分布；协方差迹增长反映滤波器对自身可靠性的置信度下降；组合多种准则可以覆盖不同的失效模式，减少漏检和误检的总体概率。               |
| 5    | **B** | 优化复杂度在因子图表示下约为O(N³)，长期运行会变成不可行；子图策略将地图划分为多个局部子图，每个子图独立优化（局部BA），子图间通过接口节点/公共观测点连接；全局回环只在必要时触发，且只影响回环路径上的子图；这种分层策略将复杂度从全局O(N³)降低为局部O(M³)+全局O(K³)。 |

## 第十四章 路径规划与避障

### 章节概述

- 主题：路径规划与避障
- 核心概念：A*算法、RRT*、MPC、DWA、ESDF

### 课后测验答案

| 题号 | 答案  | 解析                                                                                                                                                                                                                                                                                           |
| ---- | ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | **A** | 当h(n)高估时，f(n)=g(n)+h(n)可能低估某些节点的真实代价，导致算法扩展了本不该优先扩展的节点；结果可能找到次优解；但如果高估的启发函数仍然保持一致性（h(n) ≤ c(n,n') + h(n')），则A\*仍能保证找到次优解而非发散。                                                                                |
| 2    | **C** | 重连通过考察新节点附近半径r(n)内的节点，尝试将新节点作为这些节点的父节点，如果经过新节点的路径更短则更新父指针；这等价于在随机树中不断寻找更短的连接边；渐近最优性来源于：随着采样点数量的无限增加，所有可能路径都被探索到；收敛速度与采样空间的体积、障碍物分布、以及重连半径的缩放策略相关。 |
| 3    | **D** | 增大N可以改善控制性能（更好地处理延迟、预见性更好）、提高对系统非线性的处理能力，但计算复杂度随N呈多项式增长（通常O(N³)）；当N过大时，优化求解可能超时；此外，过大的N可能使优化问题病态（矩阵条件数变差），反而导致控制性能下降。                                                              |
| 4    | **A** | 分辨率过低会漏掉最优速度——机器人可能被迫选择次优轨迹甚至找不到可行轨迹；分辨率过高则计算量呈二次方增长，可能无法实时执行；工程实践中常用自适应分辨率策略：在障碍物密集区域使用细粒度采样，稀疏区域使用粗粒度采样。                                                                             |
| 5    | **B** | 延迟距离 = v × τ = 10m/s × 0.15s = 1.5m；即感知到的障碍物位置比真实位置"落后"了1.5m；如果按此信息做避障决策，机器人可能在障碍物实际位置前方1.5m处才开始避障，严重时可能碰撞；补偿方法：预测性避障（基于障碍物当前速度和方向预测未来位置）、扩大安全裕度（膨胀地图边界）。                      |

## 第十五章 集群协同感知

### 章节概述

- 主题：集群协同感知
- 核心概念：协同定位、分布式建图、一致性算法、编队控制

### 课后测验答案

| 题号 | 答案  | 解析                                                                                                                                                                                                                                               |
| ---- | ----- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | **A** | 收敛条件：ε < 1/λ_max(L)，其中L是图拉普拉斯矩阵，λ_max是其最大特征值；代数连通度 = L的第二小特征值λ₂，λ₂越小，图越稀疏连接，收敛越慢，有效协同半径受此限制；ε过大会导致算法振荡或发散。                                                            |
| 2    | **C** | 光照变化会导致相同地点的视觉特征描述子差异很大，单纯外观匹配失败；IMU提供的初始位姿可以将搜索空间从全局匹配限制到局部区域；此外，可以在特征匹配时考虑几何一致性（两帧之间的相对位姿应与IMU估计一致），使用混合准则（外观+几何）来提高匹配成功率。  |
| 3    | **D** | 通信延迟改变了信息传递的相位响应——原本负反馈的系统引入了滞后相位，可能使总相位裕度降到零以下，导致振荡或发散；这是时滞系统（Time-delay System）的控制问题，需要使用Smith预测器、记忆辅助控制、或将延迟建模为系统矩阵的一部分来设计鲁棒控制器。     |
| 4    | **A** | 市场拍卖是近似算法，只能保证获得(1-1/k)的近似比（k为agent数量），无法保证全局最优；但其分布式特性使通信开销为O(k×m)（k无人机，m任务数），远低于集中式优化的O(m!)；在大规模动态场景下具有实用性；收敛速度与任务分布的空间相关性、竞拍策略设计相关。 |
| 5    | **B** | 全连通拓扑下，所有无人机两两共享状态，信息矩阵是稠密的，定位精度理论上最高（方差最小）；但实践中：N机全连通需要N(N-1)/2条链路，10机即45条，通信带宽随N²增长；因此通常选择k近邻拓扑（每机只与最近的k机通信），在定位精度和通信开销之间取得平衡。    |

## 第十六章 嵌入式部署与硬件加速

### 章节概述

- 主题：嵌入式部署与硬件加速
- 核心概念：模型量化、TensorRT、DVFS、ROS2实时化

### 课后测验答案

| 题号 | 答案  | 解析                                                                                                                                                                                                                                                                   |
| ---- | ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | **A** | 量化精度损失与激活分布的动态范围和均匀性相关：ResNet的激活分布相对均匀，量化误差近似高斯分布；MobileNet等轻量网络使用深度可分离卷积，激活分布往往呈双峰或长尾分布，量化误差有偏，导致精度严重下降；通道级（channel-wise）量化比层级量化精度更高。                      |
| 2    | **C** | INT8量化需要将FP32权重和激活映射到INT8的256个离散值；校准过程通过统计FP32激活的分布来确定最优的量化边界（阈值）；如果校准数据与实际数据分布不一致，量化边界会偏移，导致实际推理时大量激活值被截断或聚集在少数量化级别上，精度严重下降。                                |
| 3    | **D** | 现代GPU/AI芯片的计算吞吐量远高于内存带宽（TOPS vs TB/s）；每次计算都需要从内存读取权重和写入激活值，内存访问能耗是计算的数百倍；算子融合通过将多个独立操作合并为单个Kernel，减少中间结果的内存读写（如将Conv+BN+ReLU融合为单一算子），显著降低内存访问次数和带宽需求。 |
| 4    | **A** | 满载20W时续航 = 150Wh / 20W = 7.5小时；降至10W后续航 = 150Wh / 10W = 15小时；提升百分比 = (15-7.5)/7.5 × 100% = 100%；即功耗减半，续航翻倍；但实际中需要考虑感知性能是否满足任务要求。                                                                                 |
| 5    | **B** | 内存泄漏：allocated但未释放的显存持续积累，最终导致OOM；碎片化：频繁分配/释放导致显存中出现大量不连续的小块，即使总显存充足也无法分配大块连续内存；碎片化更难调试因为症状间歇性出现；内存池通过预分配固定大小块，减少动态分配释放次数，是防止碎片化的有效方法。        |

## 第十七章 开源项目与工具链

### 章节概述

- 主题：开源项目与工具链
- 核心概念：ROS/ROS2、Gazebo、VINS-Mono、LIO-SAM、数据集

### 课后测验答案

| 题号 | 答案  | 解析                                                                                                                                                                                                                                                                               |
| ---- | ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | **A** | Vicon的精度约为1mm RMS，但标记点需要安装在无人机机体上，标记点与相机/Lidar之间的标定误差约为1-2mm，且标记点与机体存在微小弹性形变；综合误差约2-3mm；对于高精度SLAM算法（如ATE < 1cm），这个真值误差可能导致10-30%的相对评估偏差。                                                  |
| 2    | **B** | VINS-Mono采用批量优化，每帧需要迭代求解非线性最小二乘，计算复杂度高但精度好；MSCKF采用EKF，计算量小（O(N²)，N固定）但存在线性化误差累积；嵌入式选型原则：在Orin等高性能平台选VINS-Mono追求精度，在RB5等中端平台选MSCKF/OpenVINS保证实时性。                                        |

| 4    | **D** | ROS1的回调函数在单线程中随机执行，回调执行顺序不可预测；ROS2的Executor支持多种调度策略；Static executor（编译时确定执行顺序，无运行时调度开销）可以保证每帧的执行顺序和时间间隔确定性，消除运行时调度抖动（jitter），这对姿态控制的实时性至关重要。                                |
| 5    | **C** | 数据集特性对算法泛化性影响显著：EuRoC是室内场景，光照恒定、纹理丰富；ULH是户外大规模场景，包含光照变化、天气影响、重复纹理等挑战；算法在单一数据集上的优异表现不代表泛化能力；正确的验证流程应包括在多个不同特性的数据集上验证、在目标实际部署环境中进行实地测试、进行鲁棒性测试。 |
