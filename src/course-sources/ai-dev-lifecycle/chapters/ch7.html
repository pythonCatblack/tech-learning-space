AI代码生成可以分为几个层次：语法级生成、函数级生成、模块级生成、架构级生成。层次越高，AI的作用越大，但也需要更精准的Prompt和更多的审查。

7.1 代码生成的层次

语法级
如Copilot的实时补全，单行或短代码块
→
函数级

→
模块级

→
架构级
AI辅助搭建项目结构，生成基础架构代码

业务逻辑往往涉及复杂的领域知识，AI无法完全理解业务背景，但可以帮助实现模式化的逻辑。

示例：任务优先级计算

💡 提示词示例
为任务管理系统实现优先级计算逻辑。

   - 被其他任务阻塞：-50分
   - 阻塞其他任务：+10分

请使用TypeScript实现这个优先级计算函数，要求：
- 纯函数，无副作用
- 完整的类型定义
- 单元测试覆盖主要场景
- 包含JSDoc注释

请审查以下代码，指出可能的问题并提供重构建议。

关注点：
1. SOLID原则违反情况
2. 可能的性能问题
3. 错误处理不完善的地方
4. 可测试性问题
5. 安全漏洞

原始代码：
```typescript
class TaskManager {
  private tasks: any[] = [];

  addTask(task: any) {
    if (!task.title) throw new Error('Title required');
    if (!task.dueDate) throw new Error('Due date required');
    this.tasks.push(task);
    this.notify();
  }

  getTasks() {
    return this.tasks;
  }

  private notify() {
    // 发送通知的逻辑
    console.log('Task added');
  }
}
```

课后测验

第七章选择题

1. 在模块级代码生成中，如何确保AI生成的多个文件之间保持一致性和正确的依赖关系？若将模块结构建模为有向无环图（DAG），AI生成代码的顺序如何影响最终模块的正确性？如何在生成过程中引入形式化验证来保证生成的代码满足指定的接口契约？
A. 使用拓扑排序确定生成顺序；在生成过程中引入Hoare逻辑验证前置/后置条件是否满足，保证模块间契约的一致性　B. 生成顺序不影响正确性；AI可以并行生成所有文件　C. 无法保证一致性；模块级生成只能依靠AI的"涌现能力"　D. 使用贪心顺序生成；先生成被依赖最多的模块

2. 在业务逻辑生成中，若业务规则可以建模为一阶谓词逻辑的规则库，AI生成代码的过程如何形式化为从规则库到程序代码的编译转换？这种场景下，AI生成的代码正确性如何证明？
A. 将一阶谓词规则编译为执行路径，使用定理证明器验证生成的代码是否满足规则规范；代码正确性可以通过模型检查（Model Checking）证明　B. 无法证明正确性；一阶谓词逻辑的完备性决定了解的正确性无法自动判定　C. 使用贪心转换；将每条规则直接翻译为if语句　D. 使用神经网络端到端学习；输入规则描述，输出程序代码，不需要形式化验证

3. AI代码审查中，如何将"代码风格一致性"建模为可量化的优化目标？若使用信息论中的互信息（Mutual Information）来度量代码片段与目标风格的关联度，如何设计算法在有限审查预算下最大化发现风格违规的总信息量？
A. 将代码审查建模为信息获取问题；使用强化学习的Exploit-Explore权衡策略，优先审查互信息最高的代码片段，同时探索未知区域　B. 互信息越高表示风格一致性越好；遍历所有代码片段计算互信息，选取最高的片段审查　C. 无法量化风格一致性；风格是主观概念，只能人工判断　D. 使用朴素贝叶斯分类器；计算代码片段属于违规风格的概率

4. 在使用AI生成复杂算法（如任务分解）时，如何权衡生成代码的"探索性"（尝试新方法）与"利用性"（使用已知有效方法）？若将算法生成建模为多臂老虎机问题，如何确定最优的探索率ε使得在有限生成预算下获得最佳算法性能？
A. 使用UCB1算法动态调整探索率；探索率ε应随生成次数增加而递减，初期探索新方法，后期利用已知有效方法，ε* = √(2ln(T)/t)　B. 始终使用ε=0.1的固定探索率；这是经验最优值　C. 始终保持完全探索（ε=1）；探索所有可能的方法才能找到最优　D. 始终保持完全利用（ε=0）；只使用已知有效的方法

5. AI辅助代码重构中，如何形式化地定义"代码质量"的度量并将其用于指导重构方向？若将代码质量建模为多目标优化问题，目标函数应该包含哪些维度？如何在重构空间中进行搜索以找到Pareto最优的重构方案？
A. 目标函数包含：圈复杂度、耦合度、内聚度、可读性；使用NSGA-II等多目标进化算法在重构空间中搜索Pareto前沿　B. 目标函数仅包含执行效率；使用梯度下降法优化　C. 目标函数仅包含代码行数；最小化代码量即为最优重构　D. 无法定义统一的质量度量；代码质量是场景相关的

6. 在数据库查询优化的AI辅助中，如何将查询性能预测建模为机器学习问题？若使用神经网络预测给定SQL查询的执行时间，训练数据的特征空间应该如何设计以捕捉查询的语义信息和执行计划的结构信息？
A. 特征空间包含：SQL的解析树结构、表统计信息、索引可用性、历史执行计划；使用GNN（图神经网络）学习执行计划图的表示　B. 特征空间仅包含SQL文本的TF-IDF向量；使用传统ML模型如随机森林预测　C. 特征空间仅包含表的大小；使用线性回归预测执行时间　D. 无法预测查询性能；查询执行时间取决于数据库的内部状态
