## 第2章 半导体器件物理

| 题号 | 答案 | 验证状态 | 说明                                                                                                                                                       |
| ---- | ---- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | D    | ✅       | 硅原子最外层4个价电子形成的共价键具有特定的方向性和键能，禁带宽度~1.1eV直接来源于硅-硅共价键的键合能量，这是半导体特性的物理基础。                         |
| 2    | C    | ✅       | 内建电场的形成是浓度梯度引发的载流子扩散与电离杂质离子固定电荷的静电相互作用共同作用的结果，扩散过程产生内建电场，内建电场又抑制进一步扩散，最终达到平衡。 |
| 3    | B    | ✅       | 空穴是虚拟粒子，其运动涉及晶格畸变和声子散射，而电子在导带中自由运动不受晶格畸变影响，因此N型半导体中电子迁移率显著高于P型半导体中空穴的迁移率。           |
| 4    | D    | ✅       | 重掺杂引入大量电离杂质，载流子在电离杂质附近运动时发生散射，导致迁移率显著下降，这是高掺杂浓度下器件性能退化的主要物理机制。                               |
| 5    | B    | ✅       | 应变硅技术通过在沟道区引入拉伸或压缩应力调制晶格常数，减小载流子有效质量，提升迁移率，尤其对空穴迁移率的提升效果显著。                                     |

**本章要点：** 能带理论解释导体/绝缘体/半导体的区别；硅的禁带宽度~1.1eV是"完美开关窗口"；N型掺杂（磷）产生自由电子，P型掺杂（硼）产生空穴；PN结正向导通、反向截止。

## 第3章 CMOS晶体管原理

| 题号 | 答案 | 验证状态 | 说明                                                                                                                                                   |
| ---- | ---- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1    | A    | ✅       | DIBL效应的核心机制是漏极电场穿透到沟道区域，降低了源极势垒，使源极电子更容易注入沟道，导致阈值电压随沟道长度减小而降低，这是短沟道效应的主要物理来源。 |
| 2    | C    | ✅       | PMOS轻掺杂的原因在于重掺杂会导致阈值电压绝对值过大，同时空穴迁移率对掺杂浓度更敏感，轻掺杂可以优化阈值电压和驱动电流的权衡。                           |
| 3    | B    | ✅       | 沟道长度调制效应导致饱和区电流不完全饱和：当V_DS增加时，有效沟道长度略有减小，使得漏极电流继续增加。                                                   |
| 4    | C    | ✅       | FinFET三面包围从三个方向对沟道施加电场控制，增强静电控制能力，减小了耗尽区向沟道的延伸，有效抑制了短沟道效应。                                         |
| 5    | D    | ✅       | 增加纳米片数量并减小厚度可以通过多通道并行提供更大的总驱动电流，同时较薄的纳米片能够更好地抑制短沟道效应，在最大化驱动电流和保持低漏电流之间取得平衡。 |

**本章要点：** MOSFET是电压控制型器件，栅极不消耗电流；CMOS的互补设计使静态功耗趋近于零；FinFET三面包围沟道抑制短沟道效应；GAA（全环绕栅极）是最新一代晶体管架构。

## 第4章 数字电路设计

| 题号 | 答案 | 验证状态 | 说明                                                                                                                                                                           |
| ---- | ---- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1    | A    | ✅       | CMOS中NAND门需要4个晶体管（2个NMOS串联+2个PMOS并联），而AND门是在NAND门后串联一个反相器，需要6个晶体管，因此NAND门比AND门少用2个晶体管。                                       |
| 2    | B    | ✅       | 时序逻辑电路包含存储元件（触发器或锁存器）和时钟信号，使输出具有"记忆"先前输入状态的能力，这是与组合逻辑的本质区别。                                                           |
| 3    | B    | ✅       | 主从型触发器通过两个级联的锁存器实现边沿触发：在时钟的某个电平期间主锁存器跟踪输入，从锁存器保持稳定；时钟翻转时主锁存器冻结，从锁存器捕获主锁存器的状态，实现精确的边沿采样。 |
| 4    | B    | ✅       | 时序违例后触发器可能采样到亚稳态输出，在0和1之间悬停，导致后续电路逻辑错误传播，这是时序分析中必须避免的关键问题。                                                             |
| 5    | B    | ✅       | CLA通过树状结构并行计算所有位的生成信号（G=A·B）和传播信号（P=A⊕B），利用分层进位生成逻辑实现并行进位传播，将延迟从O(n)降低到O(log n)。                                        |

**本章要点：** NAND/NOR是"万能门"，可用它们组合出任何逻辑电路；组合逻辑无记忆，时序逻辑有时钟和存储元件；触发器比锁存器更适合时序控制；建立/保持时间是时序分析的核心约束。

| 2    | A    | ✅       | 多端口SRAM允许多个读/写端口同时访问，但多端口SRAM单元面积是单端口的2-3倍，在芯片面积和性能之间存在显著权衡。                           |
| 3    | A    | ✅       | Mealy型状态机输出是当前状态和输入的函数，响应更快，但可能产生毛刺，时序验证更复杂；而Moore型输出仅依赖当前状态，更稳定但可能响应较慢。 |
| 4    | B    | ✅       | 轮询策略基于时间片进行轮转授权，每个主设备在获得授权后移到队列末尾，保证公平性，避免固定优先级导致的饥饿问题。                         |
| 5    | B    | ✅       | L1缓存通过比较CPU访问的地址与缓存中存储的标签（Tag）来确定命中或未命中，同时检查有效位（Valid Bit）确保数据有效。                      |
| 6    | B    | ✅       | Kogge-Stone树是并行前缀加法器的典型结构，其延迟为 ⌈log₂n⌉·t_FA。对于32位CLA，⌈log₂32⌉=5，但实际工程实现中通常取6级 t_FA 延迟。         |
| 7    | B    | ✅       | 二进制编码需要 m 个触发器满足 2^m ≥ k（状态数）。对于25个状态，2^4=16 < 25 ≤ 2^5=32，因此需要5个触发器。                               |
| 8    | C    | ✅       | 由 Setup 约束 T_clk ≥ t_cq + t_logic_max + t_setup + t_skew，代入得 250 ≥ 50 + t_logic_max + 30 + 20，解得 t_logic_max ≤ 150ps。       |

**本章要点：** ALU是CPU的核心执行单元；超前进位加法器（CLA）将进位延迟从O(n)降到O(log n)；寄存器文件是多端口SRAM；FSM分为Mealy型和Moore型；存储器层次结构平衡速度、容量和成本。

## 第6章 处理器架构基础

| 题号 | 答案 | 验证状态 | 说明                                                                                                                                                |

| 2    | A    | ✅       | 伪共享产生于两个核心访问同一缓存行中的不同数据变量，即使它们没有逻辑共享数据，也会因缓存行的物理同一性而频繁触发缓存失效协议，开销巨大。            |
| 3    | A    | ✅       | 寄存器重命名主要解决WAR（写后读）和WAW（写后写）两种伪数据依赖，通过将逻辑寄存器映射到多个物理寄存器，使写操作可以先于之前的写完成。                |
| 4    | B    | ✅       | TAGE采用几何长度的多个历史表，能够捕捉不同长度的分支模式，从最近几次分支到数千次之前的分支，提供更精准的全局上下文预测。                            |
| 5    | B    | ✅       | 超标量处理器发射宽度受限于执行单元数量、寄存器文件端口数、唤醒逻辑复杂度以及物理设计中的线延迟等综合因素。                                          |

**本章要点：** 流水线让CPU"同时做多件事"；三种流水线冒险：数据冒险、控制冒险、结构冒险；超标量每个周期可发射多条指令；分支预测猜对满载、猜错清空；乱序执行打破指令顺序；MESI协议保证多核缓存一致。
